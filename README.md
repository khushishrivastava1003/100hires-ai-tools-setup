# AI Tools Setup Portfolio

## Objective

Complete the setup process for Cursor, GitHub, and AI-assisted development tools while documenting the learning process, challenges encountered, and solutions implemented.

## Tools Installed

- Cursor IDE
- GitHub
- Claude Code for VS Code
- Codex – OpenAI's Coding Agent

## Steps Completed

1. Created a GitHub account.
2. Connected GitHub to Cursor.
3. Installed Cursor.
4. Explored Cursor's interface and extension marketplace.
5. Installed Claude Code.
6. Installed Codex.
7. Created a public GitHub repository.
8. Created and edited a README.md file.
9. Documented the setup process and findings.

## Challenges Encountered

### Challenge 1: Navigating Cursor's Interface

Installing Cursor itself was straightforward. However, after installation, I spent some time trying to locate the Claude Code and Codex extensions. Initially, I was working in Cursor's Agent interface and could not understand why the extensions shown in tutorials were not available.

#### Solution

I researched the issue by watching tutorials and exploring the application further. Through this process, I discovered that Cursor has a separate Editor Window where the VS Code extension marketplace is available. Once I switched to the Editor Window, I was able to locate and install Claude Code.

### Challenge 2: Finding the Correct Codex Extension

After successfully installing Claude Code, I still could not find Codex when searching the marketplace.

#### Solution

I continued investigating and realized that the extension was listed as "Codex – OpenAI's Coding Agent" rather than simply "Codex." After refining my search, I was able to locate and install the extension successfully.

## Key Learnings

* GitHub's interface was intuitive and beginner-friendly, making it relatively easy to create and manage a repository.
* Cursor was a completely new tool for me, which made the learning process more challenging but also more interesting.
* I learned the importance of exploring documentation, tutorials, and alternative approaches when the first solution does not work.
* Small differences in software interfaces can create confusion, so carefully investigating the environment is important before assuming something is unavailable.
* By the end of the project, I was able to successfully install the required tools, create a repository, and become more comfortable working with unfamiliar software independently.

## Reflection

This project reinforced the value of persistence and self-directed learning. Although I encountered a few obstacles while navigating Cursor and locating the required extensions, I was able to resolve them through research and experimentation. The experience gave me greater confidence in approaching unfamiliar tools and finding solutions independently.
